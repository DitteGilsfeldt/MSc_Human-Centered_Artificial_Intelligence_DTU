Remote Development with VS Code

Instead of uploading / downloading our files constantly or working through ThinLinc, we can use the remote development feature of Visual Studio Code to work directly on the HPC system.

The step-by-step guide here is based loosely on the official guide by Microsoft.

Note: If you are not on DTU wifi you may need to connect with a VPN first or set up ssh keys (see: https://www.hpc.dtu.dk/?page_id=4317).

Issues with VS Code version 1.86

Note: These issues have been fixed in the latest release, cf., the release notes and this GitHub issue. If you still have issues, either upgrade your VS Code version, or (if that fails) follow the guide below.

From version 1.86 VS Code upgraded the minimum requirements for the remote hosts it will connect to, and the DTU HPC system does not (currently) meet these.

Workaround: Microsofts recommends getting around this by using version VS Code version 1.85 in Portable Mode (this way, you can have the frozen 1.85 version for HPC work and the newest version for "normal" work). To set this up:

  1. Download the zip installation of VS Code version 1.85 (links adapted from here)
    Windows: Click this link to download.
    Linux: Click this link to download.
    Mac: Click this link to download.
  2. Unzip the downloaded folder to a suitable location, i.e., not your Downloads. Any folder will work.
  3. Follow the instructions at this link: Enable Portable Mode

First-Time Connection

If you have already followed these steps (successfully) once, please scroll down to the Future Connections section.

  1. Install the Remote Development extension in VS Code if you haven't already.


  2. Open the Remote Explorer window


  3. Select "Remotes (Tunnels/SSH) in the drop down menu


  4. Click the '+' to add a New Remote


  5. Type in the SSH command you normally use to log in to the HPC. Replace "<username>" with your own DTU user name. See also the guide Connecting to an HPC Terminal.


  6. Pick any of the top options. This is the file VS Code will store the SSH command for future use - you do not need to access this file yourself


  7. Press the "Connect" button in the lower right corner


  8. Select "Linux" as the platform of the remote host, since the HPC runs a Linux system. You may be asked this again - just pick Linux.


  9. Enter your DTU password to complete the login


  10. You can now select a folder/directory on the HPC where you want to work. This works the same as when you run VS Code on your personal computer. You may be prompted for your password again


  11. If you open the embedded terminal in VS Code you should now see that it is connected to the HPC. You can now run 'linuxsh' or bsub job scripts like you would if you connected with SSH

Future Connections

Once you've followed the steps above, you should see the host you logged in to in the list of SSH remotes. Click one of the highlighted buttons to log in again. You will then be prompted for your DTU password and you should be on. You may be asked for the host platform again: pick Linux.
