Connecting to an HPC Terminal

NOTE: If you are not on DTU wifi you may need to connect with a VPN first or set up ssh keys (see: https://www.hpc.dtu.dk/?page_id=4317).

Additional information can also be found here: https://www.hpc.dtu.dk/?page_id=2501

Via SSH (Recommended)

To connect to HPC run one of the following in a terminal on your personal computer:

  • ssh <username>@login.hpc.dtu.dk
  • ssh <username>@login2.hpc.dtu.dk
  • ssh <username>@login.gbar.dtu.dk
  • ssh <username>@login2.gbar.dtu.dk

Here, <username> is your DTU user name, e.g., your study number. Then, type in your DTU password. If it times out, try another one. The node may be overloaded.

You have now logged on to a login node on the HPC! If you want to run something, then run

linuxsh

to log on to work node. Please, do not run any heavy stuff on the login nodes!
